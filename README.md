# React Tic-Tac-Toe

A React implementation of the classic Tic-Tac-Toe game, based on React's introductory tutorial. It tracks board state, alternates X and O, detects a winner, and keeps move history so players can jump back to earlier turns.

## Tech stack

- React 18
- JavaScript
- Create React App

## Run locally

```bash
npm install
npm start
```

Open the local development URL shown by Create React App (normally `http://localhost:3000`).

## Production build

```bash
npm run build
```

## Status

A learning project focused on React components, props, state, event handling, and rendering lists.
